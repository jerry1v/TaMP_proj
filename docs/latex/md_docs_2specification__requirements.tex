Система предназначена для выполнения следующих функций:\+


\begin{DoxyItemize}
\item регистрация пользователей;
\item авторизация пользователей;
\item шифрование данных алгоритмом AES;
\item получение хеша SHA1;
\item вычисление квадратного корня методом Ньютона;
\item внедрение сообщения в музыкальный файл;
\item взаимодействие клиента и сервера по сети.
\end{DoxyItemize}
